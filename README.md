# Excel Lab 4 – Cleaning and Structuring Retail Data

## 📌 Overview

This lab focuses on **cleaning, standardizing, and structuring** the DMart retail dataset using Microsoft Excel.

## 🎯 Tasks Completed

* Converted raw data into an **Excel Table**
* Applied professional table formatting
* Standardized city and region values
* Corrected inconsistent data entries
* Used **Flash Fill** and **AutoFill**
* Created and used **Custom Lists**
* Prepared clean data for reporting and analysis
